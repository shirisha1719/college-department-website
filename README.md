\# College Department Website



A simple web application that provides information about a college department, including the home page, faculty details, and contact information.



\## Features



\* Home Page

\* Faculty Page

\* Faculty Details

\* Contact Page

\* Department Information

\* Responsive Design



\## Technologies Used



\* HTML5

\* CSS3

\* Git

\* GitHub



\## Git Collaboration



\* Three developers work on separate feature branches

\* Developer 1 – Home Page

\* Developer 2 – Faculty Page

\* Developer 3 – Contact Page

\* Meaningful commits for each feature

\* Push feature branches to GitHub

\* Merge feature branches into the main branch

\* Create a merge conflict by modifying the same file

\* Resolve the merge conflict

\* Verify the final integrated website
